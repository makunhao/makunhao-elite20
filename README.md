## 我在做什么

- 用 KSTAR 循环记录每件事的「预期 R̂ / 实际 R / 差值 ΔR」；
- 把重复动作提炼成可调用技能（6 个，均有使用记录）；
- 所有结论附可复算路径，不写无法核查的判断。
