## 三、明确没拿的

| 没拿 | 原因 |
|---|---|
| 仓库的测试结论 | 需要 Python 3.13 + uv，本机 3.10；未跑就不写"测试通过" |
| git 提交历史 | clone 失败，zip 无 `.git`；不编造提交数 |
| GitHub 页面截图 | 浏览器无外网；不给"看起来像截图"的替代品 |
| 仓库作者的背景信息 | 与分析无关，避免把人和代码混为一谈 |

## 四、引用规范

- 文件路径与行号均来自本次下载的 `main` 分支（2026-11-16）。
- 版本以 `pyproject.toml` 为准；README/CLAUDE/TASKS 的说法若与代码冲突，以代码为准并在文中注明。
- 所有统计数字可用 `十三_C5A_仓库分析.md` 第十节命令复算。

## 五、如果只记一条

> 分析别人的仓库，**先数、再读、最后判断**。
> 数不出来的是猜测，读不进去的是摘要，只有能被别人复算的判断才算分析。
